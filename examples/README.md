# Public examples

Two public photos from the Valencia set, included unchanged from the public render:

- `20261101-121758` — L’Oceanogràfic, used as the album cover.
- `20261101-164119` — Ciutat de les Arts, used as the València album cover.

Each folder contains:

- `scene.jpg` — rectified left eye, used by the 2.5D mesh.
- `sbs.jpg` — full side-by-side pair for 3D glasses.
- `thumb_sbs.jpg` — small pair used by the gallery wiggle.
- `thumb.jpg` — flat thumbnail fallback.
- `depth.jpg` — grayscale depth map.
- `meta.json` — dimensions, depth source and mesh anchor.

These files are public on randompics.de. Private photos, originals and share tokens are
not part of this repository.
